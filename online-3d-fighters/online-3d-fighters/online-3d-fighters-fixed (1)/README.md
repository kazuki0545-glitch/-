# 3D FIGHTERS ONLINE

URLを友達に送って別々のPCから対戦できる、2人用のブラウザー格闘ゲーム（擬似3Dポリゴン描画）。

## ローカル起動

Node.js 18以上をインストールし、このフォルダーで:

```bash
npm install
npm start
```

http://localhost:3000 にアクセスします。インターネット上の別のPCから対戦するには次の「公開」が必要です。

## 公開して友達と対戦する（Renderの例）

1. このフォルダーの中身をGitHubリポジトリにアップロード。
2. https://render.com/ の **New → Web Service** で該当GitHubリポジトリを選択。
3. Environment: **Node**、Build command: `npm install`、Start command: `npm start` を設定してデプロイ。
4. 発行された `https://○○.onrender.com` にアクセス。
5. PC1で「部屋を作る」→「URLをコピー」。PC2にそのURLを送り、開いてもらいます。

**注意:** Render等の無料プランではスリープや開始の遅延、通信制限があり得ます。サーバーが再起動すると部屋情報は消えます。URLを知る人が部屋に入れる方式です。最大2人/部屋で、観戦は未対応です。現在はキーボード操作・1ラウンド・ルームメモリ保存のみです。低遅延のためサーバーとユーザーの距離が近いリージョンを選んでください。

## 操作

PLAYER 1: `A` / `D` 移動、`W` ジャンプ、`F` パンチ、`G` キック、`H` ガード。

PLAYER 2: `←` / `→` 移動、`↑` ジャンプ、`J` パンチ、`K` キック、`L` ガード。

攻撃判定とHP・KOはサーバー側で管理。ネットワーク越しにポジションと攻撃を同期します。

## 設計上の制約

3Dモデルエンジンではなく、Canvasに立体形状を投影する**擬似3D**試作です。公開URL自体をこのパッケージが発行するわけではなく、デプロイ先が必要です。プレイヤーの表示はサーバーのスナップショット（約15Hz）なので回線が悪いとカクつく可能性があります。本番用には補間・接続復旧・認証等を追加してください。
